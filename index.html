Approach

How I run an event.

  1. 01

    Pick the right rooms

    Not every show deserves a booth. I build the calendar by asking where our buyers actually spend time, then decide whether each event gets a booth, a speaking slot, a sponsorship, or a hosted dinner.

  2. 02

    Speak to each persona

    Different personas care about different things. What gets an operations leader to stop at the booth isn't what gets a finance leader to take a meeting. I use AI tools like Claude and Clay to start building the campaign and learn who's attending, then shape the message, demo, and outreach around them.

  3. 03

    Follow up while it's still warm

    The event is the start. I set clear follow-up rules with sales, build the nurture in HubSpot, and report on what each show actually produced, so next year's calendar is based on real numbers.
