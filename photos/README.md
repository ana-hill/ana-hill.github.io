# Event photos go in this folder

1. Drop your photo here. JPG or PNG both work.
2. Use simple file names with no spaces, like `booth-1.jpg` or `dinner-2.jpg`.
3. Open `events.js` and add a line with the file name and an optional caption.

Tips:
- Landscape (wide) photos look best. The first photo shows extra large, so pick your best one for it.
- Keep each photo under about 1 MB so the site loads fast on phones.
  On a Mac: open the photo in Preview, go to Tools → Adjust Size, and set the width to 2000.
- Only post photos you have permission to share, especially ones showing customers or other attendees.
